# PRD: 地質図検索 WebGIS (geo_map)

## 1. 概要
- **一言で何を作るか**: 産業技術総合研究所（GSJ）の地質図幅・20万分の1日本シームレス地質図 V2・火山地質図および日本地質学会「巡検スポット」を統合検索・重ね合わせ・比較閲覧できるシングルページ WebGIS アプリケーション。
- **解決する課題**: 5万分の1地質図幅（763図幅以上）、20万分の1シームレス地質図、北海道立総合研究機構（HRO）図幅、学会巡検案内書が別々のサイト・資料に散在しており、調査地域の図幅比較や巡検地点の地理的把握に手間がかかる。
- **期待される成果**: フルスクリーン地図上で図幅検索・最大 4 図幅の透過重ね合わせ・凡例ルーペ・断面図/PDF 閲覧・巡検コースのクラスタリング/LOD 閲覧と URL パーマリンク共有を即座に行える。

## 2. 対象ユーザー
| ユーザー | 目的 | 主な操作 | 成功の定義 |
|---|---|---|---|
| 地質学研究者・学生・フィールド調査者 | 調査地の地質図幅・シームレス地質図・巡検スポットの探索と比較 | 図幅検索・絞り込み、最大 4 図幅重ね合わせ、凡例ルーペ、巡検コース展開、URL 共有 | 対象地域の図幅・凡例・PDF・巡検案内書を迷わず特定・比較できる |

## 3. スコープ
### MVPで作る機能
- フルスクリーン Leaflet 地図（地理院タイル 4 種：白地図/淡色/標準/写真、図郭枠表示、現在地移動）
- 左ドロワー（`[地質図 | 巡検スポット]` タブ切替、略称対応サジェスト、表示範囲内フィルタ、詳細フィルタ：発行年・縮尺・資料有無）
- 右インスペクタ（最大 4 図幅の重ね合わせ・透過度・順序管理、`[凡例]` 2.8 倍ルーペ、`[断面図]`、`[詳細・PDF]`）
- 20 万分の 1 シームレス地質図 V2 XYZ タイル重畳＋地点地質照会
- 日本地質学会「巡検スポット」レイヤー（ピクセル距離クラスタリング・コース展開・Stop 前後ナビゲーション・案内書リンク）
- URL ハッシュパーマリンク（`lat`, `lng`, `z`, `maps`, `seamless`, `trip`）＋`localStorage` 設定保存（日英切替 `JP`/`EN`・ダークモード）
- Python データパイプライン（取得・正規化・厳格スキーマ検証・GeoJSON 生成）

### MVPで作らない機能（Non-goals）
- サーバー側 DB・ユーザー認証・ブラウザ上での図幅データ編集機能
- ビルドパイプライン（Webpack/Vite/Node.js）依存

### 将来機能
- 未確定（必要に応じて `docs/TASKS.md` に追加）

## 4. ユーザーストーリーと受け入れ基準

### US-001: 地質図幅の検索と重ね合わせ比較
- As a 調査者, I want 図幅名や表示範囲から地質図を検索し複数枚を重ねて比較したい, so that 境界付近や異なる縮尺の地質解釈を対比できる。
- 受け入れ基準:
  - WHEN 左ドロワーでキーワード入力または地図種別/詳細フィルタを変更する THEN 条件に一致する図幅一覧が表示される
  - WHEN 図幅を選択して右インスペクタに追加する THEN 最大 4 図幅まで個別透過度・重ね順を操作でき、凡例・断面図・PDF リンクを参照できる
- 検証方法:
  - 手動確認: `python scripts/serve.py` で起動し、検索・4図幅追加・透過度変更・ルーペ表示を確認
  - 自動テスト: `tests/test_audit_suite.py`（`map_catalog.json` 770件・`map_index.geojson` 769件のスキーマ検証）

### US-002: 巡検スポットの広域クラスタリングと詳細展開
- As a 調査者, I want 全国の巡検コースを地図上で俯瞰し個別コースの Stop を順に辿りたい, so that 巡検案内書と地質図を対応づけて予習・復習できる。
- 受け入れ基準:
  - WHEN 広域表示で巡検スポットを表示する THEN ピクセル距離ベースの集約ピル（`Nコース`）が表示される
  - WHEN コースを選択する THEN 全 Stop へフィットし、破線ルート・案内書リンク・Stop ポップアップ内前後移動が動作する
  - WHEN 巡検スポット CSV に重複 ID や同一コース内カテゴリ混在がある THEN `build_field_trips_geojson` が `ValueError` で拒否する
- 検証方法:
  - 手動確認: 巡検スポット ON/OFF・コース展開・前後ナビを確認
  - 自動テスト: `TestFieldTrips` 全 5 テスト

### US-003: URL パーマリンクによる状態復元
- As a 調査者, I want 現在の地図位置・重ね合わせ図幅・巡検コースを URL で共有したい, so that 同じ閲覧状態をすぐ再現できる。
- 受け入れ基準:
  - WHEN 地図移動・オーバーレイ追加・シームレス切替・巡検展開を行う THEN URL ハッシュ（`#lat&lng&z&maps&seamless&trip`）が同期され、リロード時に復元される
- 検証方法:
  - 手動確認: 状態変更後にリロードして同じ位置・レイヤーが復元されることを確認

## 5. 制約
- **技術的制約**: フロントエンドはビルド不要の Vanilla HTML/CSS/ES Modules（Leaflet 1.9.4 のみ外部 CDN）。Python パイプラインは `requests>=2.31.0`, `beautifulsoup4>=4.12.0` を使用。
- **法務・ライセンス**: 背景地図は国土地理院タイル、地質図データは産総研地質調査総合センター（政府標準利用規約第 2.0 版 / シームレス V2 は CC BY 4.0）、ソフトウェアは MIT License。
- **プライバシー**: 認証・個人データ収集なし。設定のみブラウザ `localStorage` に保存。

## 6. 成功指標
- **定量的指標**: データパイプライン・スキーマ監査テスト（`tests/test_*.py`）がすべてパスすること。
- **定性的確認方法**: デスクトップおよびモバイル（720px 以下タブ切替）で検索・重ね合わせ・巡検閲覧が支障なく操作できること。
