# 産総研 地質図検索 WebGIS

Leaflet.js (v1.9.4) と Vanilla JavaScript を用いて構築した、産業技術総合研究所（産総研）の各種縮尺（5万分の1・20万分の1等）の地質図幅を検索・閲覧・比較するためのシングルページ WebGIS アプリケーションです。

## 主な機能

- **ベースマップ表示・切り替え**:
  - 初期表示は国土地理院の淡色地図をマップエリアいっぱいに表示し、右下にズームコントロール、左下にスケールバーを配置。
  - 左サイドバーから **淡色地図 / 標準地図 / 航空写真（シームレス空中写真）** をワンクリックで切り替え可能。
- **日本語 / 英語（`JP` / `EN`）切り替え**:
  - 左サイドバーヘッダーの `JP` / `EN` ボタンで UI 表記・図幅名・著者名・サジェスト候補・検索対象を一括切り替え可能。
- **検索サジェスト & クイックオプション**:
  - 検索欄へのフォーカス・入力時に **図幅名・著者名のサジェスト候補（種別バッジ付き）** を表示（`↑`/`↓` キーで選択、`Enter` で確定、`Esc` で閉じる、`/` または `Ctrl+K` / `Cmd+K` で検索欄へフォーカス）。
  - **表示範囲内のみ**: 現在の地図表示範囲内に映っている図幅だけに一覧・件数を連動絞り込み。
  - **図郭枠を表示**: 青い図郭インデックス枠の表示/非表示を切り替え、重ねた地質図のみを観察可能。
- **折りたたみ式詳細フィルター**:
  - **発行年**: デュアルレンジスライダーによる範囲指定（データ最小年〜現在年、将来年も自動追従）。
  - **縮尺・シリーズ**: `1:50,000`・`1:200,000` 等の縮尺マルチセレクト。
  - **著者・その他**: 著者名、発行機関、資料有無（説明書PDFあり・凡例あり・原図JPGあり）でのマルチセレクト絞り込み。
- **3カラム・サイドバーUI & 最大4図幅同時比較**:
  - **左サイドバー**: 検索・各種フィルター・表示中の地質図（最大4枚）・常時表示の該当図幅一覧（リスト ↔ 地図ポリゴンの双方向ホバー連動、全体表示ボタン付き）。
  - **XYZタイル優先オーバーレイ（WMSフォールバック対応）**: `maxNativeZoom` 対応により高倍率ズーム（15〜18）でもタイルが消えず拡大表示を維持。最大4図幅まで同時重ね合わせ・不透明度スライダー（0%〜100%）に対応。
  - **右サイドバー（詳細情報 & 地質凡例）**: 現在オーバーレイ表示中の地質図のうち **画面内で最も広く表示されている図幅** の書誌情報（図幅名・発行年・縮尺・著者・詳細情報/原図JPGリンク）と **地質凡例** を自動表示。説明書は軽量版 PDF を優先して「説明書を見る」ボタンに設定し、詳細版 PDF がある場合は別途「詳細版PDF」ボタンを表示（いずれも新規タブ表示）。
  - **凡例ホバー拡大鏡（2.5倍ルーペ）**: 凡例画像にマウスを乗せると、角丸正方形（`180×180px`）の拡大鏡が追従表示されます（端で見切れないクランプ制御・別タブ拡大表示対応）。

## 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク不使用）
- [Leaflet.js v1.9.4](https://leafletjs.com/)
- Google Fonts（Noto Sans JP）

## ローカルでの起動方法

### Windows（ワンクリック起動）
プロジェクト直下の [start_app.bat](start_app.bat) をダブルクリック（またはクリック）するだけで、ローカル HTTP サーバーが起動し、既定のブラウザで自動的にアプリが開きます（終了時は開いたコマンドウィンドウを閉じるか `Ctrl + C` を押してください）。

### コマンドラインから起動する場合
`fetch` API を使用して GeoJSON を読み込むため、ローカル HTTP サーバー経由でアクセスしてください（`file://` 直開きでは CORS 制約により動作しません）。

```bash
# 付属のランチャーを使う場合（自動で空きポート検出しブラウザを起動）
python scripts/serve.py

# 標準の http.server や npx を使う場合
python -m http.server 8000
# または
npx serve .
```

## 図幅データの追加・更新方法

`scripts/build_map_catalog.py` を使うと、GSJ Linked Data のメタデータ HTML（日本語カタログページ含む）と TileJSON から `map_catalog.json` および `map_index.geojson` を自動生成できます。`--series` で 5万分の1以外のシリーズも指定可能です。

```bash
pip install -r requirements.txt

# 5万分の1地質図幅 (g050) の取得例（1486: 大河原など）
python scripts/build_map_catalog.py \
  --series g050 \
  --map-id 501 502 503 504 505 506 507 508 509 510 511 512 1486 \
  --output data/map_catalog.json \
  --geojson-output data/map_index.geojson
```

## GitHub Pages での公開手順

本リポジトリには `.github/workflows/pages.yml` が含まれています。

1. `main` ブランチへプッシュします。
2. GitHub リポジトリの **Settings > Pages** を開き、**Source** で **GitHub Actions** を選択します。
3. ワークフロー完了後、公開 URL からアプリケーションにアクセスできます。
